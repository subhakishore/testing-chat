MantaRay HW Manager includes a Dynamic Host Configuration Protocol (DHCP) server, which is by
default running but doesn't provide any service before configuring it. DHCP can provide addresses
and, with the help of Trivial File Transfer Protocol (TFTP) or Hypertext Transfer Protocol (HTTP),
boot images, and configuration files to the managed network nodes. The DHCP or TFTP services
are provided to both L2 and L3 subnets. L3 subnets require a DHCP relay to be running at the
edge of the L2 network.
If addresses are provided by MantaRay HW Manager or DHCP to the managed hardware, they can
also be fixed at the managed nodes when requested. After the connectivity to the managed node
is established, the user can request MantaRay HW Manager to alter the setting of a source IP
address at the managed node (DHCP or fixed).
Protocols
Multiple protocols are used between MantaRay HW Manager and the managed nodes:
Secure Shell (SSH)
Remote Management Protocol (RMCP) + Intelligent Platform Management Interface (IPMI)
Simple Network Management Protocol (SNMP)
HTTPS (Redfish)
If DHCP is used, then also Bootstrap Protocol (BOOT) DHCP, TFTP, and HTTP are used.

Rack with factory settings
AirFrame Rack is delivered with an asset file. The asset file contains a set of nodes data, including
their physical location in the rack. When an asset file with desired IP addresses is imported to
MantaRay HW Manager, MantaRay HW Manager can assign those addresses to nodes and establish
connectivity. The corresponding subnet has to be configured in MantaRay HW Manager and
enabled.
Inspecting server nodes
Inspector can be run on server nodes to collect detailed hardware information. This is done by
PXE booting the server node to a specific inspector agent.
Server provisioning
Desired operating system (OS) can be installed on server nodes with PXE booting.
Server deep inspection and provisioning rely on booting the server with the PXE procedure. The
PXE procedure uses DHCP, TFTP, and HTTP protocols. Those protocols are sent and received by a
server without Virtual Local Area Network (VLAN) tagging, so untagged traffic must be supported.
